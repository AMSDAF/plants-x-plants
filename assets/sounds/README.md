# Sons do Plants x Plants

Identidade sonora **híbrida orgânica**: timbres naturais (kalimba, marimba, madeira) com brilho de chiptune, combinando o tema botânico e o visual em pixel.

## Efeitos (`sfx/`)

Efeitos originais, sintetizados pela equipe com script próprio. Não há restrição de licença. Formato: WAV mono, 16 bits, 44,1 kHz, volumes relativos já equilibrados no arquivo.

| Arquivo | Quando toca |
| --- | --- |
| `ui_move.wav` | Mover o cursor em menus, seleção, golpes e placa lógica |
| `ui_confirm.wav` | Confirmar, avançar de tela, abrir painel ou submenu |
| `ui_back.wav` | Voltar de tela, fechar painel ou submenu |
| `ui_invalid.wav` | Nome inválido, relé rejeitado ou resposta errada na placa |
| `ui_type.wav` | Digitar ou apagar letras do nome |
| `step_grass.wav` | Passos na estufa, a cada 50 pixels percorridos |
| `door_open.wav` | Entrar ou sair de uma fachada |
| `hatch.wav` | Descer ou subir pela escotilha do subsolo |
| `dialogue_blip.wav` | A cada três letras reveladas no diálogo |
| `relay_on.wav` | Ligar relés, refletor, válvula, canais, portão ou pegar a chave |
| `battle_start.wav` | Entrar na arena contra um guardião |
| `hit_thorn.wav` | Golpe de cacto, aloe, hera venenosa, pimenta e planta carnívora |
| `hit_light.wav` | Golpe de girassol, orquídea e trevo |
| `hit_impact.wav` | Planta recebe dano |
| `boosted.wav` | Golpe potencializado pela fórmula lógica |
| `switch_out.wav` / `switch_in.wav` | Planta sai e reserva entra na arena |
| `faint.wav` | Planta murcha (vida zerada) |
| `paralysis.wav` | Planta paralisada perde o turno |
| `low_hp.wav` | Vida da planta ativa do jogador fica abaixo de 25% |
| `jingle_victory.wav` | Vitória na batalha e campanha concluída |
| `jingle_defeat.wav` | Derrota na batalha |

## Músicas (`music/`)

Faixas em OGG, tocadas em loop e com transição suave. O jogo procura estes nomes; um arquivo ausente apenas deixa aquele momento sem música.

| Arquivo | Momento |
| --- | --- |
| `menu.ogg` | Menu, seleção de personagem, nome e prólogo |
| `exploration.ogg` | Exploração da estufa e interiores |
| `basement.ogg` | Subsolo |
| `battle.ogg` | Batalha contra guardião (para no resultado, quando entra a vinheta) |
| `ending.ogg` | Campanha concluída |

### Créditos

Todas as faixas estão em domínio público (CC0) no OpenGameArt; o crédito não é obrigatório, mas é registrado por reconhecimento. Os arquivos foram convertidos para OGG Vorbis e tiveram o volume igualado (cerca de -18 LUFS), sem outras alterações.

| Arquivo | Faixa | Autor | Fonte |
| --- | --- | --- | --- |
| `menu.ogg` | Flowerbed Fields [Loop] | Zane Little Music | https://opengameart.org/content/flowerbed-fields-loop |
| `exploration.ogg` | Puppy Playing in The Garden (versão sem latido) | Spring Spring | https://opengameart.org/content/puppy-playing-in-the-garden |
| `basement.ogg` | Crystal Cave (song18) | cynicmusic | https://opengameart.org/content/crystal-cave-song18 |
| `battle.ogg` | Trouble in the Garden | HaelDB | https://opengameart.org/content/trouble-in-the-garden |
| `ending.ogg` | Post-Adventure Tea Party | Zane Little Music | https://opengameart.org/content/post-adventure-tea-party |
