# Tipografia da interface

Atkinson Hyperlegible Next, Regular e Semibold, em TTF estático.
Fonte: [repositório oficial](https://github.com/googlefonts/atkinson-hyperlegible-next).
Revisão utilizada: `7925f50f649b3813257faf2f4c0b381011f434f1`.

Os arquivos originais não foram modificados. A licença SIL Open Font License
1.1 e o aviso de direitos autorais acompanham a distribuição em `OFL.txt`.

`UiTheme`, pertencente a `Game`, carrega as duas fontes uma vez, incluindo
caracteres latinos, acentos e pontuação da interface. O atlas de 96 pixels
mantém detalhe na renderização física; o jogo preserva coordenadas lógicas.
Se uma fonte faltar, utiliza o outro peso ou a fonte padrão da raylib.
